## Purpose

Add `agent-gateway transcribe`, which exposes the existing OpenAI, Gemini,
and OpenRouter audio transcription on the CLI. The command:

- parses the flags;
- rejects unsupported vendors with `-32021` before any I/O;
- infers the MIME type from the file extension;
- calls a `GatewayTranscribing`, which is `ProductionGatewayExecutor()` in
  production;
- prints the transcript (`--output text`) or `{model,text,vendor}` JSON
  (`--output json`).

Diagnostics go only to stderr.

## Changes

### `GatewayTranscriptionCommand.swift` (new, internal symbols)

- `enum GatewayTranscriptionOutputFormat: String, Sendable { case text, json }`
- `struct GatewayTranscriptionCommandOptions: Equatable, Sendable` with the
  fields `vendor: GatewayVendor`, `model: String`, `file: String`,
  `mimeType: String?`, `language: String?`, `prompt: String?`,
  `apiKeyEnvironment: String?`, `baseURL: String?`, `timeoutSeconds: Int`
  (default 120), and `output: GatewayTranscriptionOutputFormat` (default
  `.text`).
- `struct GatewayTranscriptionCommandOutcome: Equatable, Sendable` with the
  fields `status: Int32`, `standardOutput: String`, and
  `standardError: String`.
- `extension AppCommand`:
  - `func transcriptionOptions(_ arguments: [String]) throws -> GatewayTranscriptionCommandOptions`
    - It follows the `decisionOptions` loop.
    - Allowed flags: `--vendor`, `--model`, `--file`, `--mime-type`,
      `--language`, `--prompt`, `--api-key-environment`, `--base-url`,
      `--timeout-seconds`, `--output`.
    - Any other token, including `--` or a bare positional argument, throws
      `Error.unknownArgument(token)`.
    - A missing next value throws `Error.missingValue(flag)`. So does a next
      value that starts with `--` or is empty, as in `decisionOptions`.
    - If a flag is repeated, the last value wins.
    - Validation after the loop:
      - `--vendor` is absent or `GatewayVendor(rawValue:)` returns nil:
        `missingValue("--vendor")`;
      - `--model` is absent: `missingValue("--model")`;
      - `--file` is absent: `missingValue("--file")`;
      - `--timeout-seconds` is not an `Int`:
        `missingValue("--timeout-seconds")`;
      - `--output` is not `text` or `json`: `missingValue("--output")`.
    - Do not reject known vendors that lack transcription support here.
      The run step does that.
  - `func runTranscription(_ options: GatewayTranscriptionCommandOptions, transcriber: any GatewayTranscribing) async -> GatewayTranscriptionCommandOutcome`
    - Order:
      1. `validateGatewayTranscriptionVendor(options.vendor)`
      2. resolve the MIME type (`options.mimeType ?? inferred`)
      3. build `GatewayTranscriptionParams` (`audioFile: URL(fileURLWithPath: options.file)`)
      4. `try await transcriber.transcribe(params)`
      5. format the output
    - Success, `.text`: `standardOutput = text + "\n"`, status 0.
    - Success, `.json`: one line from a private
      `Encodable struct {model, text, vendor: String}` using
      `vendor.rawValue`, encoded with `[.sortedKeys, .withoutEscapingSlashes]`,
      plus `"\n"`, status 0.
    - `GatewayRPCError e`: `standardError = "transcription failed (\(e.code)): \(e.message)\n"`,
      status 1.
    - Any other error: `"transcription failed: \(error.localizedDescription)\n"`,
      status 1.
- `func inferGatewayTranscriptionMIMEType(path: String) -> String?`
  - It looks only at the lowercased `URL(fileURLWithPath:).pathExtension`.
  - The map:
    - `wav` -> `audio/wav`
    - `mp3`, `mpga`, `mpeg` -> `audio/mpeg`
    - `m4a`, `mp4` -> `audio/mp4`
    - `webm` -> `audio/webm`
    - `ogg`, `oga` -> `audio/ogg`
    - `flac` -> `audio/flac`
    - `aac` -> `audio/aac`
  - Anything else returns nil.
  - If inference returns nil and no `--mime-type` was given, `runTranscription`
    throws or maps
    `GatewayRPCError(code: -32602, message: "cannot infer audio MIME type from file extension '<ext>'; pass --mime-type")`.
    For an empty extension, use `''` as `<ext>`.

### `Command.swift`

- Add `"transcribe"` to the `run()` allow-list array.
- Add a `case "transcribe":` to `runStreaming()`:
  1. `let options = try transcriptionOptions(Array(arguments.dropFirst()))`,
     so that parse errors propagate to `main.swift` and give exit 2;
  2. `let outcome = await runTranscription(options, transcriber: ProductionGatewayExecutor())`;
  3. write `outcome.standardOutput` to `FileHandle.standardOutput` and
     `outcome.standardError` to `FileHandle.standardError`, skipping either
     one when it is empty;
  4. `return outcome.status`.
- `usage`:
  - Add, after the `subscription-usage` line:
    `agent-gateway transcribe --vendor <openai|gemini|openrouter> --model <id> --file <path> [--mime-type <type>] [--language <code>] [--prompt <text>] [--api-key-environment <name>] [--base-url <url>] [--timeout-seconds <n>] [--output text|json]`
  - Add a short paragraph, in the same style as the others, covering:
    - the supported vendors;
    - that the MIME type is inferred from the extension unless
      `--mime-type` is given;
    - the 25 MB limit;
    - that `text` prints the transcript and `json` prints
      `{model,text,vendor}`;
    - that credentials are read from the environment variable named by
      `--api-key-environment` (vendor default otherwise), and that the CLI
      never prints them;
    - that other vendors fail with `-32021`;
    - the example
      `agent-gateway transcribe --vendor openai --model whisper-1 --file meeting.m4a`.

## Invariants / Pitfalls

- The CLI must never stat, open, or read the audio file. Leave that to
  `loadGatewayTranscriptionAudio`.
- MIME inference must run after the vendor check, so that an unsupported
  vendor with an unknown extension reports `-32021`.
- Stdout carries only the transcript or JSON. Nothing goes to stdout on
  failure.
- Never print secret values, params dumps, or request URLs. The Gemini key
  is in the query string.
- Do not add fields to `GatewayClientOptions`. Do not change
  `parseOptions` or `writeJSONLine` visibility.
- Do not make `GatewayTranscriptionResult` `Codable`.
- Do not edit these files:
  - `GatewayTranscription.swift` (wave 1);
  - `GatewayTranscriptionRequest.swift`;
  - `main.swift`;
  - `README.md` (plan `transcribe-readme`);
  - the design docs.
- Respect `--help` and `-h`. `run()` already returns usage, and
  `runStreaming()` returns 0 early. Do not change that ordering.
- Swift files stay under 1000 lines. `Command.swift` is currently 368 lines.

## Tests (`Tests/AgentGatewayAppCoreTests/TranscribeCommandTests.swift`)

Setup:

- Use `import Foundation`, `import Testing`, `@testable import AgentGateway`,
  and `@testable import AgentGatewayAppCore`.
- Add a test-only `final class RecordingTransport: @unchecked Sendable` with
  an `NSLock`. It records `(URLRequest, Int)` calls and returns a canned
  `(Data, HTTPURLResponse)`. Expose `var transport: GatewayTranscriptionTransport`.
- Each test builds its options with `AppCommand(arguments: []).transcriptionOptions([...])`
  and runs `runTranscription(options, transcriber: GatewayTranscriptionPipeline(environment: env, transport: stub.transport))`.
- Temp audio files are a few bytes, use a UUID name, and are removed in a
  `defer`.

Cases (input -> expected outcome):

1. `--vendor openai --model whisper-1 --file <tmp>.mp3 --language ja --prompt Stria --api-key-environment TEST_OPENAI_KEY`,
   environment `["TEST_OPENAI_KEY": "fixture-secret"]`, stub answers 200
   with `{"text":"hello"}`:
   - outcome `status 0`, `standardOutput "hello\n"`, `standardError ""`;
   - the stub has exactly 1 call;
   - the request is a POST to
     `https://api.openai.com/v1/audio/transcriptions`;
   - `Content-Type` has the prefix `multipart/form-data; boundary=`;
   - the `Authorization` header is not nil;
   - the body (decoded as UTF-8 with lossy conversion) contains
     `name="model"\r\n\r\nwhisper-1`, `name="language"\r\n\r\nja`,
     `name="prompt"\r\n\r\nStria`, and `Content-Type: audio/mpeg`;
   - `fixture-secret` is in neither stdout nor stderr.
2. Same as case 1 plus `--output json`: stdout is exactly
   `{"model":"whisper-1","text":"hello","vendor":"openai"}\n`, status 0, 1
   call.
3. `--base-url https://example.invalid/v1 --timeout-seconds 7`: the request
   URL is `https://example.invalid/v1/audio/transcriptions`, the recorded
   timeout argument is 7, and `request.timeoutInterval` is 7.
4. `inferGatewayTranscriptionMIMEType`:
   - every extension in the table -> its mapped type;
   - `x.WAV` -> `audio/wav`;
   - `x.xyz` -> nil;
   - `noext` -> nil.
5. `--mime-type audio/wav` with an `.mp3` file: the body contains
   `Content-Type: audio/wav`.
6. A `.xyz` file with no `--mime-type`: status 1, stderr contains `-32602`
   and `--mime-type`, stdout is empty, and the stub has 0 calls.
7. Vendors `anthropic`, `cursor`, and `claude-code`, with
   `--file /nonexistent/dir/a.xyz`: status 1, stderr has the prefix
   `transcription failed (-32021)`, stdout is empty, and the stub has 0
   calls.
8. Missing file `/nonexistent/dir/a.mp3` with the fixture key: status 1,
   stderr has the prefix `transcription failed`, and the stub has 0 calls.
9. Oversized file:
   - create an empty `.mp3` temp file and call
     `FileHandle(forWritingTo:).truncate(atOffset: 25_000_001)`, which makes
     a sparse file;
   - result: status 1, stderr contains `-32602` and `25 MB`, and the stub
     has 0 calls.
10. HTTP failure:
    - the stub answers 429 with `{"error":{"code":"insufficient_quota"}}`,
      and in a second case with `{"error":{"code":"rate_limit_exceeded"}}`;
    - in both cases: status 1, stdout is empty, and stderr contains
      `transcription failed (-32010)`, `vendor HTTP 429`, and the matching
      code string.
11. Empty environment, `--vendor openai` with no `--api-key-environment`:
    status 1, stderr contains `-32011` and `OPENAI_API_KEY`, and the stub
    has 0 calls.
12. Parsing:
    - no `--vendor`, `--vendor nope`, no `--model`, and no `--file` each
      throw `missingValue` for the right flag;
    - `--output yaml` throws `missingValue("--output")`;
    - `--timeout-seconds abc` throws `missingValue("--timeout-seconds")`;
    - `--bogus x` throws `unknownArgument("--bogus")`;
    - `--file` as the last token throws `missingValue("--file")`.
13. `AppCommand(arguments: ["transcribe", "--vendor", "openai"]).run()`
    returns `""`, and `AppCommand(arguments: []).usage` contains
    `agent-gateway transcribe`.
